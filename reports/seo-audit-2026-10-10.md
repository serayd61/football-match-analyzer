# SEO denetimi — Google kuralları × footballanalytics.pro (10 Ekim 2026)

Kaynak: Google Search Central (SEO Starter Guide, Google Images best practices, Organization / Breadcrumb structured data dokümanları). Canlı site Googlebot UA ile `curl` edilerek, kod ise `src/app/(site)` ve `src/components/site` üzerinden incelendi.

## 1. Google ne istiyor? (araştırma özeti)

| Konu | Google'ın güncel kuralı | Not |
|---|---|---|
| `<title>` | Sayfaya özgü, kısa, içeriği doğru anlatan başlık. Google başlık bağlantısını `<title>` + sayfa başlıklarından üretir. | Anahtar kelime yığmak spam politikasına girer. |
| Meta description | Kısa, sayfaya özgü, en önemli noktaları içeren özet. Snippet çoğu zaman sayfa içeriğinden gelir; description sadece bazen kullanılır. | |
| `<meta name="keywords">` | **Google kullanmıyor.** | Eklemenin faydası yok. |
| Başlık hiyerarşisi (h1/h2) | Erişilebilirlik için anlamlı; Google sıralama için sıraya veya sayıya bakmaz. | |
| Görsel alt metni | "En önemli görsel sinyali." Görselin içerikle ilişkisini anlatan kısa, bağlamsal metin. `alt`'a anahtar kelime doldurmak spam sayılır. | Her resim için **anlamlı** alt; her resim için "keyword" değil. |
| Görsel dosya adı | Kısa ve açıklayıcı (`my-new-black-kitten.jpg` > `IMG00023.JPG`). | |
| Görsel yerleşimi | İlgili metnin yanında, `<img>` ile (CSS arka plan görselleri indekslenmez). | |
| Yapısal veri (JSON-LD) | Zengin sonuçlar için; işaretlenen bilgi sayfada görünür olmalı. Organization için logo ≥112×112 px, ana sayfada. | FAQ zengin sonucu kaldırıldı; FAQPage eklemenin görünür faydası yok. |
| URL / canonical / hreflang | Kelimeli URL, tek canonical, dil sürümleri için hreflang. | |
| Sitemap | `lastmod` okunur; `changefreq` ve `priority` **yok sayılır**. | |
| Mobil kullanılabilirlik | Yakınlaştırma engellenmemeli (`user-scalable=no` Lighthouse/WCAG hatası). | |

## 2. Site karşılaştırması: zaten doğru olanlar

- Her sayfada özgün `<title>` + description, 4 dilde (`generateMetadata`).
- Canonical + hreflang (en/de/it/tr + x-default) hem `<head>`'de hem sitemap'te.
- `<html lang>` doğru; 1 adet H1, anlamlı H2 yapısı.
- Üyelere özel sayfalar (`/picks`, `/dashboard`, `/account`, `/login`) `noindex`; sitemap yalnız herkese açık URL'leri listeliyor.
- Arma görselleri `next/image` ile, `width/height` + `loading="lazy"`.
